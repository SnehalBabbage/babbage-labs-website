                    <h2>Project "AetherTrace"</h2>

                    <p class="project-subtitle">Layer 7 Cloud Asset & API Discovery Tool</p>

                    <p><strong>The Problem:</strong> In modern, sprawling cloud environments, "shadow IT" and undocumented API endpoints are the single greatest external risk. You can't secure what you don't know you have.</p>

                    <p><strong>The Invention:</strong> AetherTrace goes beyond simple subdomain brute-forcing. It actively crawls JavaScript files, mobile app binaries, and public code repositories to find, fingerprint, and map an organization's hidden cloud assets and API schemas. It's a "shadow recon" tool for the modern stack.</p>

                    <h2>Project "Nexus"</h2>

                    <p class="project-subtitle">Active Directory Lateral Movement Pathfinder</p>

                    <p><strong>The Problem:</strong> Once inside a network, attackers don't just "hack" their way to a target. They follow complex, pre-existing permission paths. Finding the shortest and stealthiest path to Domain Admin is a graph theory problem.</p>

                    <p><strong>The Invention:</strong> Nexus is a post-exploitation tool that ingests data from tools like BloodHound and generates a dynamic "attack tree" in real-time. It's designed to help red teams (and by extension, defenders) answer one question: "From this compromised workstation, what is the most efficient path to total network compromise?"</p>

                    <h2>Project "Chrysalis"</h2>

                    <p class="project-subtitle">Context-Aware Smart Fuzzer for IoT Protocols</p>

                    <p><strong>The Problem:</strong> Standard fuzzers are "dumb." They just send random data. This is inefficient for finding vulnerabilities in proprietary, stateful protocols used by IoT, medical, and industrial control (ICS) devices.</p>

                    <p><strong>The Invention:</strong> Chrysalis is a fuzzer that first *learns* the protocol by observing legitimate traffic. It then uses this "protocol-aware" state model to generate intelligent, mutated, and far more effective inputs, allowing it to find deep, complex vulnerabilities that other fuzzers miss.</p>
